Setup em 2 passos

O primeiro comando clona as skills do Pedro pro seu ~/.claude/skills/. O segundo registra marketplaces e instala os plugins. Pré-requisito: Claude Code instalado e logado.

passo 1

Skills do Pedro

curl -fsSL https://raw.githubusercontent.com/pedrorezende/claude-skills/main/install.sh | bash

Cria ~/.claude/skills/<nome>/ pra cada skill. Pra instalar só uma: ... | bash -s -- impeccable. A skill atualizar-app é de projeto, adapte caso a caso.

passo 2

Marketplaces + plugins

/plugin marketplace add anthropics/claude-plugins
/plugin marketplace add agricidaniel/claude-seo
/plugin marketplace add jezweb/ui-ux-pro-max-skill

/plugin install context7@claude-plugins-official
/plugin install frontend-design@claude-plugins-official
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill
/plugin install superpowers@claude-plugins-official
/plugin install skill-creator@claude-plugins-official
/plugin install code-review@claude-plugins-official
/plugin install code-simplifier@claude-plugins-official
/plugin install security-guidance@claude-plugins-official
/plugin install github@claude-plugins-official
/plugin install vercel@claude-plugins-official
/plugin install claude-seo@agricidaniel-seo

Cole tudo no Claude Code, um por vez. 3 marketplaces + 11 plugins.

Editar / criar skill

Skills do Pedro ficam em ~/.claude/skills/<nome>/SKILL.md. Edite, salve, Claude recarrega na próxima invocação. Plugin skills vivem em ~/.claude/plugins/cache/<mkt>/<plugin>/<versao>, read-only (atualiza via /plugin update). Pra criar nova, use skill-creator.
