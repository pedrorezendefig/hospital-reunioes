- **O Painel não se atualiza sozinho.** Só o Quadro se atualiza a cada 30
  segundos. No Painel, troque de aba e volte, ou recarregue a página.
- **O selo de Demanda encerrada para no dia em que ela fechou.** Reabra a
  Demanda para ele voltar a se atualizar.
- **Anexo é só imagem**, até 10 por Demanda, e é apagado quando ela encerra.
  Documento vai por outro caminho, com o nome do arquivo escrito na resposta.
- **Sem relatório nem gráfico.** O Painel tem os quatro números do alto e
  nenhum número por pessoa.
- **Sem filtro no Quadro.** Para achar uma Demanda encerrada, use a busca do
  Histórico.
- **O aviso é só por e-mail**, nos três casos de
  [Os e-mails da aba](../os-e-mails-da-aba/).
- **As Demandas nascem à mão**, pelo assistente ou pelo formulário. Não há
  importação de lista.
- **Quem entra na aba é Super Admin do app inteiro.** Não existe perfil só da
  Tecnologia.
- **O planejamento com a IA cuida só das decisões de negócio.** As decisões
  técnicas ficam com a Vitta, depois do sim.
