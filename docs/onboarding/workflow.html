O ciclo

Três estágios. Uma palavra pra disparar tudo.

Os dois primeiros estágios são você + Claude planejando e codando. O terceiro é uma palavra: /start. Ela lê o estado do projeto e leva até o deploy sozinha.

01
Planeja

Você ativa o modo plano nativo do Claude Code.

Plan mode Conversacional

Você descreve em português o que quer mudar. O Claude lê o código relevante, propõe abordagem, mostra trade-offs. Você aceita, recusa, refina. Quando o plano tá claro, você aprova — o Claude sai do plan mode e implementa.

Atalho: Shift + Tab + Tab · ou rodar claude --plan

02
Coda

O Claude escreve o código aprovado.

Auto Você revisa

Sai do plan mode e o Claude executa o plano. Edita arquivos, roda lint, confere tipos, testa o que dá pra testar. Você acompanha, intervém quando precisa. Resultado: working tree com mudanças prontas.

03
Sobe pra produção

Você digita /start. O resto é automático.

/start Auto-deploy ~10 min

A skill lê o diff do working tree, infere tipo (fix/feature/chore) e área, cria branch, gera chronicle 🟡 com plano inferido, e encadeia o ciclo inteiro até produção: commit · push · PR · code-review · security-review · self-approval · merge · deploy via Coolify · regeneração de docs/spec/.

Por baixo do capô

Quais skills moram dentro de quais.

Você invoca uma. Ela orquestra todas as outras. Time iniciante decora só a raiz. 

/start entry point único
├─ detecta contexto (diff, branch, issue mencionada)
└─ /ship --from-diff motor do ciclo
   ├─ git branch · gh pr create cli
   ├─ /spec chronicle 🟡 inferido do diff
   ├─ /code-review gate
   ├─ /security-review gate
   ├─ gh pr review --approve · gh pr merge --squash cli
   └─ /deploy ship subskill principal
      ├─ MCP Coolify · 9 gates pre-flight · health check + rollback
      └─ /spec update ~10 min
         └─ 9 agents REVERSA scout · architect · ... · reviewer

/issue subskill independente
└─ criar · listar · pegar · comentar · fechar gh cli

Cola rápida

Cinco comandos cobrem tudo.

Comando Quando usar
Shift+Tab+Tab "Antes de mexer no código, quero pensar com o Claude."
/start "Já codei (ou já planejei). Sobe isso pra produção."
/issue new "Quero registrar um bug ou ideia sem trabalhar agora."
/deploy status "A produção tá saudável?"
/deploy rollback "Subi algo que quebrou, volta."
